# Alpaca UI/UX 深度审计检查清单（Heuristic Checklist）

在执行全站或模块级设计审计时，对照本清单逐项自检：

## 1. 结构与渐进披露清单（Progressive Disclosure）
- [ ] **高频字段首屏优先**：核心标题、核心状态、常用分类/标签是否在视口前两屏内可见？
- [ ] **大体积控件收纳**：是否有超过 6 行的 Textarea、复杂配置表单直接平铺？（必须收纳在 `MetadataSection` 或抽屉内）。
- [ ] **常驻输入框降噪**：侧栏、列表顶部是否有常驻的非搜索类表单？
- [ ] **操作入口收敛**：工具栏按钮 $\le 4$ 个，溢出项是否收敛至「更多…」下拉菜单？

## 2. 跨模块对称性清单（Cross-Module Parity）
- [ ] **元数据面板结构一致**：所有文档类型侧栏是否均使用 `<MetadataSection title="..." defaultOpen>` 分组？
- [ ] **三栏工作台组件一致**：
  - 标签多选是否统一使用 `<TaxonomyMultiSelect />`？
  - 沉浸写作是否统一使用 `<MarkdownEditor />`？
  - 列表项高度、头像、副标题徽章间距是否统一？
- [ ] **阅读沉浸视图一致**：
  - 电子书、PDF 与待读文章的左侧目录（TOC）收起/展开机制是否一致？
  - 侧栏评论 Tab 是否均有计数徽章？
  - 沉浸退出入口是否明确且唯一？
- [ ] **返回导航一致**：全局返回按钮是否均采用统一规范图标与文字？

## 3. 弹窗与浮层清单（Dialogs & Overlays）
- [ ] **圆角统一**：所有 Modal 容器是否均为 `14px` 圆角（禁止 12px/16px/20px）？
- [ ] **遮罩与毛玻璃**：是否统一为 `rgba(15, 12, 8, 0.52)` + `backdrop-filter: blur(4px)`？
- [ ] **关闭按钮统一**：右上角关闭按钮是否均为 32px 统一类名或结构？
- [ ] **禁止私造确认框**：删除、覆盖、放弃编辑是否均调用 `requestAppConfirm` / `<ConfirmDialog />`？

## 4. 纸墨隐喻与色彩清单（Metaphor & Color Integrity）
- [ ] **浅色模式羊皮纸底色**：背景使用 `--admin-bg`（#f4efe7），面板使用 `--admin-surface`（#fffdf8），禁止纯白 #ffffff 孤岛。
- [ ] **深色模式温润灰黑**：背景使用 `--admin-bg`，面板使用 `--admin-surface-strong`，禁止脱离系统变量的写死色值。
- [ ] **拒绝高饱和冷色**：未读、选中、高亮使用暖色调 `--admin-warm`（#c07d3e）与 `--admin-save`（#775333）。
- [ ] **无技术暴露文案**：提示中无 HTTP 状态码、变量名、英文残留。
